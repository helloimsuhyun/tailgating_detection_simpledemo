🚪 CCTV Vision Module for Autonomous Security Robot Deployment – Simple Demo for capston design 1

A simple Capstone Design 1 demo for validating the key vision modules 
(tailgating detection, QR-ID tracking, BEV fusion) prior to full system integration.


- **Tailgating Detection** — YOLO + tracking–based door In/Out analysis matched with access logs to detect tailgating.
- **QR ID Tracking** — Multi-camera tracking with QR-vest verification and QR–DB ID matching.
- **BEV & Multi-Camera Fusion** — Pixel detections projected to BEV coordinates with cross-camera track association.
